# Course requirement alignment

The 2026 Engineering Introduction brief requires a problem definition with first-hand evidence and boundaries, runnable implementation, technical trade-offs, AI-use logging, value/ethics analysis and a clear statement of which default assumption is challenged.

This repository supports the implementation section:

- real MVSA-Single conflict/control metadata;
- LoRA detector and Omni/VL routing scripts;
- deterministic UI demo plus explicit real-model CLI;
- strict metric audit and raw evidence preservation;
- AI usage log with prompts, edits and reasons;
- related-work positioning without a false novelty claim.

The team should write Chapter 1 and Chapter 3 in its own words. The course brief explicitly prohibits AI from writing those sections; this repository therefore supplies evidence and engineering artifacts, not a substitute for the team's signed judgment.
