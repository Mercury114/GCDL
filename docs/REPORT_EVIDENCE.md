## 3. 工程解释

严格指标暴露出一个重要问题：在三分类冲突样本中，允许输出视觉标签或文本标签的宽松规则无法测量“是否忠实于视觉事实”。因此后续实验应把严格视觉对齐率作为主指标，同时报告一致样本效用、人工复核率、延迟和假阳性成本。

## 4. 平衡隔离评估的新证据

原100条冲突样本视觉标签严重失衡，因此新增102条分层冲突集（每类34条）和51条控制集（每类17条）。训练集排除了这153条评估样本。平衡视觉 LoRA 的训练 loss 为0.3857，冲突集严格视觉对齐率为39.22%，控制集为37.25%；Omni 对应为33.33%和19.61%。新检测器在153条隔离样本上的受限 token 评估为 TP=13、FP=5、FN=89、TN=46，F1=21.67%。接入新 detector 后的端到端冲突严格视觉对齐率为34.31%，控制集为19.61%。这些结果必须与视觉支路结果区分，不能用39.22%替代系统指标。

## 4. 答辩演示顺序

1. 打开 Streamlit Demo，展示一次冲突样本的 detector 状态和 route trace。
2. 切换阈值，展示高置信度视觉裁决、中等置信度人工复核和一致样本 Omni 路由。
3. 展示 `evidence/metrics_audit.json`，说明旧宽松指标与严格指标的差异。
4. 展示 58% -> 60% 的负结果，解释为何只加文字警告不足。
5. 最后展示真实模型 CLI，说明 Demo 模式与实验模式严格分离。

## 5. 双通道候选主方案

独立文本分类器和视觉 LoRA 分别预测三分类极性，预测不一致才触发冲突路由。该 detector 在隔离样本上的 F1 为70.48%，端到端冲突视觉对齐率39.22%，相比 Omni 基线33.33%绝对提升5.89个百分点；一致控制集从19.61%提升到31.37%。这组数字来自 `evidence/dual_channel_summary.json`。
